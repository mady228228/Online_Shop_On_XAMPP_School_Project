# Online_Shop_On_XAMPP_School_Project
This my school project about new system for online shop "Comfort Shop"
For launching:
1. Download XAMPP
2. Launch it and start MySQL and Apache
3. Unzip zip into "C:\xampp\htdocs"
4. import sql.sql into URL "localhost](http://localhost/phpmyadmin/index.php?route=/server/import"
5. Open "http://localhost/sekbob/" in any browser
More information about project in documentation "Murzabek_Madi_OnlineStoreWebSite.pdf"
